# Kshitij Saxena | Full Stack Developer Portfolio

A premium portfolio. Built with a focus on performance, cinematic animations, and a sleek dark-mode experience to showcase full-stack expertise and high-impact projects.

## 🚀 Key Features

- **Cinematic UI**: Custom-built with Framer Motion for smooth, high-end transitions and typing animations.
- **Dynamic Projects**: Bento-style project cards featuring real-time screenshots and detailed technical descriptions.
- **Expertise Focused**: Highlights core competencies in Backend Development, Frontend Development, and Data Structures.
- **Secure Communication**: Fully functional contact form integrated with FormSubmit for direct-to-email messaging without page redirects.
- **Performance Optimized**: Built on Vite with zero-config deployment readiness.

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Framer Motion
- **Icons**: Lucide React, React Icons
- **Forms**: FormSubmit (AJAX integration)
- **Deployment**: Vite, Vercel
